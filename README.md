A tabloid front page summing up the world's news of Tuesday 24 November 2026: 31 stories from 7 regions, led by Jensen Huang's return to Nvidia. `main.ts` (Node 22, standard library only) draws the 1024x1024 front page with a hand-written bitmap font and PNG encoder, and writes it to `/output/entry.png`.

Run it with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.

Entry for the [news-image-20261124](https://make.fun/c/news-image-20261124) competition on make.fun.
